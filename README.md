# Raj Gajjar's 3D Portfolio

Hello there! I'm Raj Gajjar, engineering high-fidelity digital systems. Focused on AI architecture and precise technical interfaces.

Welcome to the source code of my 3D interactive portfolio. 

Checkout the live version at [https://rajgajjar.in](https://rajgajjar.in)

## Tech Stack

- Next.js
- React
- React-three-fiber (Three.js)
- DREI
- GSAP (Animations)
- Zustand (State Management)
- Tailwind CSS

## Deployment

This portfolio is automatically built and deployed using GitHub Actions. To configure it for your own domain, simply update your GitHub Pages settings to point to your custom domain.
